# Updating TeaTools

## Install an offered update

The installed app checks for new releases and shows an update prompt when one is available.

1. Finish anything you want to do in the current session.
2. Choose **Install and restart**. TeaTools downloads the update, closes, applies it and restarts.

Choose **Not now** to keep your current version. Nothing is downloaded or installed when you decline; TeaTools can offer the update again at a later check.

If the update check or download fails, you can continue using your current version. You can also download and run the installer from the [official releases page](https://github.com/tea-tools/teatalk/releases).

## Move from an older portable copy

1. Close the running portable copy of TeaTools.
2. Download the signed [TeaTools v0.1.0-beta.3 installer for Windows x64](https://github.com/tea-tools/teatalk/releases/download/v0.1.0-beta.3/TeaTools-win-Setup.exe).
3. Run `TeaTools-win-Setup.exe`.
4. Use the installed copy for future sessions.

Older portable copies require manual updates. Running one from its old folder does not switch it to the installed version.
